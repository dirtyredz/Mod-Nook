## Shot list

Numbered in the order they should appear on the page. Capture on a **fresh config**, since that is
what a new install looks like.

| # | Shot | File | Why it earns a slot |
|---|---|---|---|
| 1 | The mod list, full screen on the bat backdrop | `01-mod-list.png` | The first thing anyone sees, and it shows the panel is not a floating box |
| 2 | A mod page with mixed row types — checkbox, cycle, slider, text | `02-settings.png` | Proves the controls are the game's own |
| 3 | An info icon hovered, tooltip open | `03-description.png` | Answers "where did the descriptions go" before it is asked |
| 4 | The list editor open on Bigger UI's `Canvases` | `04-list-editor.png` | The headline feature; one row per entry instead of a comma-separated line |
| 5 | The key-capture dialog mid-press | `05-key-binding.png` | The other thing a text box handles badly |
| 6 | Reset confirmation *(optional)* | `06-reset.png` | Shows it asks first |

**Worth capturing at a raised UI scale as well.** Not fitting the larger font is the specific
complaint this mod exists to answer, so a side-by-side at 1.5× scale would carry more weight on the
page than any description of it.
